园区绿植智能管理

GreenKeeper.js —— 零依赖的园区绿植可视化管理插件。在平面图上点选位置新增绿植、上传展示照片，按养护周期自动提醒施肥 / 放药 / 修剪，并沉淀完整维护台账。

① 新增绿植点工具栏「新增绿植」，在地图上单击落点，填写档案并上传照片。
② 养护作业点击地图上的绿植标记，选「施肥 / 放药 / 修剪」记录作业。
③ 状态预警超过养护周期的植株边框变橙 / 变红，可一眼识别待办。
④ 拖拽调整编辑模式下可直接拖动标记改位置，数据自动存本地。
数据保存在浏览器 localStorage 的 greenkeeper.data.v1；点「导出」可下载 JSON 台账，也可用「导入」还原。
